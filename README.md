Nest.js_Padel_Club_Original es mi proyecto de backend mas grande hasta el momento, el mismo consta de las siguientes funciones:
-Inicio de sesion.
-Registro.
-Json Web token.
-Auth (Para validar el acceso a las funciones mediante el token).
-Encriptado de contraseña.
-Sistema de grupos.
-Sistema de partido.
-Sistema de elo.
-Sistema de historial de los partido.
-Sistema de notificaciones.
